# Art Project — Backend

Серверна частина проєкту (API, бізнес-логіка, база даних).

---

## 🏗 Архітектура проєкту

Проєкт розділений на два незалежні репозиторії:

- **Frontend:** [Клієнтська частина проєкту](https://github.com/tavorotuk/art-project-frontend)
- **Backend:** [Серверна частина проєкту](https://github.com/tavorotuk/art-project-backend)

---

## 🌿 Git Flow

- **`develop`** — **основна гілка за замовчуванням (Default branch)**. Уся розробка ведеться тут.
- Нові завдання розробляються у фіче-гілках (`feature/<назва-фічі>`) та зливаються через Pull Request у гілку `develop`.
- **`main`** — стабільна релізна гілка для продакшену.

---

## ⚙️ Початок роботи

Склонувати репозиторій та переконатися, що ви на гілці `develop`:

```bash
git clone <backend-repo-url>
git checkout develop
```

Для **`back-end`** розробки використовується гілка `dev_breus`

Гілка **`dev_breus`** має Опис проекту в файлі DEV_STUCTURE.md
